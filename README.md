# Azure Lab

Hands-on labs where I practice IT support and identity management tasks on Microsoft Azure, building toward a career in **Tier 1 Support / Service Desk**.

Everything here is done in my own environment with **fictional users and data**. Each project documents the steps, screenshots, and what I learned.

---

## Projects

| Project | What it covers | Tools |
|---|---|---|
| [Tier 1 Support Lab with Microsoft Entra ID](./IT Support Lab with Microsoft Entra ID) | Creating and configuring users, groups and roles, simulating failed sign-ins and account lockout, troubleshooting with sign-in logs, password reset, and a full simulated support ticket | Microsoft Entra ID, Azure Portal |

---

## Skills practiced

- User account management (create, disable, update profiles)
- Access control with groups and administrative roles
- Password reset and locked account handling
- Sign-in log analysis and error code lookup
- Ticket documentation: classification, priority, diagnosis, resolution
- Writing technical documentation for a knowledge base
